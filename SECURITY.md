# Security policy

This repository is public. Do not publish credentials, internal deployment configuration, real device identifiers, customer location records, or vulnerability details in public issues. Report vulnerabilities privately using GitHub private vulnerability reporting if enabled, or contact the maintainers through a private channel. Rotate any exposed credentials; removing a file from the latest revision does not remove it from history.

See [V2 security policy](v2/SECURITY.md) for the experimental Go server. Public CI must not use internal self-hosted runners or deployment secrets.
